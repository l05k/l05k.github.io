欢迎来到我的博客！这个站点由 **Markdown 驱动**：你（或任何 AI Agent）只需要往 `content/` 文件夹里放一个 `.md` 文件，推送后文章就上线了。

## 写作格式示例

写文章就是写 Markdown。目前支持：

- 段落与 **加粗**、*斜体*、~~删除线~~、`行内代码`
- [链接](https://github.com) 与图片
- 有序列表、无序列表
- 引用块
- 代码块
- 分割线

### 一段代码

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"

print(hello("Markdown"))
```

## 数学公式

公式写法和 Obsidian 里完全一样，行内用 `$...$`：

质能方程 $E = mc^2$，以及欧拉恒等式 $e^{i\pi} + 1 = 0$。

块级公式用 `$$...$$`（独立成行）：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
